# Quick Actions Plugin for StatusBar

Quick action buttons widget for [StatusBar](https://github.com/hytfjwr/StatusBar).

## Features

- Configurable action buttons in the status bar
- Event-driven updates (no polling)

## Install

In StatusBar preferences → Plugins → Add Plugin:

```
hytfjwr/statusbar-plugin-quickactions
```

## Development

```bash
make build      # Release build
make dev        # Build & install locally
make release    # Build & publish GitHub Release
```

## Requirements

- macOS 26+
- [StatusBar](https://github.com/hytfjwr/StatusBar)
